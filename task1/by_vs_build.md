## Бизнес-возможности TO-BE

Легенда «Тип» (по цвету на карте):
- **УП** : уникальное конкурентное преимущество (зелёный);
- **ПЗ** : отсутствует, работает дорого или создаёт риски (красный);
- **НЗ** : не является зоной трансформации (белый).

Классы: 
**SaaS** : сервис поставщика, только настройка; 
**PaaS** : управляемая облачная платформа, своя логика минимальна; 
**On-premise (сохраняется)** : существующие системы HQ (SAP ERP, Promo Engine, Smart Fulfillment) не переносятся из-за ограничения срока.
