### Бизнес функции

Департамент развития 
- покупает конкурента
- управляет магазинами
- финансирует выезд ИТ-бригады (комадировочные, ФОТ)
- оплачивает контракты с поставщиком услуг кассового софта в каждом магазине
- оплачивает платные лицензии ПО в каждом магазине (Windows, Server, SQL)
- оплачивает покупку серверов в каждый магазин
Коммерческий департамент
- управляет менеджерами-товароведами
- управляет ассортиментом, остатками и промо
Менеджер-товаровед/Team Data Integration
- читает письма на email data-integration@vitastore.ru
- работает с файлами товаров со старой кассы в формате CSV или XLS
- сопоставляет Excel-таблицы через функцию VLOOKUP по штрихкодам с базой SAP ERP до двух недель
- обрабатывает несопоставленные данные вручную (скорость: 500 позиций в час, объем: 80% позиций в файле)
- заводит новую номенклатуру (загружает файл с полным сопоставлением в SAP ERP)
ИТ-дирекция
- руководит ИТ-бригадой
- управляет разработкой SAP ERP, Promo Engine, Smart Fulfillment
- отправляет ИТ-бригаду для подключения магазина
ИТ-бригада/Team Store Ops:
- выезжает в магазин
- настраивает/администрирует локальные сервера на территории магазина и покупает новые при поломке
- обновляет ПО с платными лицензиями
- разворачивает "толстый клиент"
- подключается к старой кассе (front-office) 
- снимает дамп базы товаров со старой кассы в формате CSV или XLS
- отправляет файл на email data-integration@vitastore.ru
- разрабатывает все уникальные драйвера для взаимодействия с кассовым аппаратом
- разрабатывает и поддерживает SAP ERP, Promo Engine, Smart Fulfillment
SAP ERP:
- управление магазинами
- управление ассортиментом
- управление ценами
- управление программой лояльности
- управление товародвижением
- формирует пакет обновлений (XML) и в 02:00 ночи по FTP рассылает обновлённые прайс-листы на локальные серверы (Local DB) всех магазинов, включая новые
- списывает балы по программе лояльности
Кассовый "толстый клиент"
- обращается через сеть интернет в SAP ERP за программой лояльности
- работает с кассовыми терминалами через уникальные драйвера и протоколы
- управляет печатью фискальных чеков
Касса:
- бьет чеки
- работает через "толстый клиент"
- работает онлайн и оффлайн
Покупатель:
- покупает товар (в магазине и онлайн)
- просят списать/накопить баллы по карте лояльности

### Описание текущей ИТ-инфраструктуры
HQ Cloud:
  - on-premises SAP ERP (товары, цены)
  - on-premises Promo Engine (лояльность)
  - on-premises Smart Fulfillment (товародвижение, онлайн-заказы)
Кассовый софт:
- собственный локальный сервер у каждого магазина
- локальная база данных (MS SQL Server / PostgreSQL) 
- кассовый "Толстый клиент", который взаимодействует с уникальным терминалом, SAP ERP
- Разнородные платежные терминалы с уникальными драйверами

#### Бизнес-цели

* Оптимизировать операционные затраты:
- снизить затраты на персонал через оптимизацию процессов
- выявить внутренние решения с высокой стоимостью владения
- оценить возможность замены внутренних решений на готовые облачные сервисы
- сократить срок процесса подключения в сеть с 2х недель до 5 дней
- сократить ТСО магазина на 40%
- внедрить единые стандарты оплаты

#### Промежуточное решение

* Требования:
  * провести аудит текущий решений
  * выбрать стек облачных решений (SaaS/PaaS) для замены локальных серверов
  * минимизировать участие человека в процессе миграции нового магазина
  * рассчитать ТСО при отказе от локального железа
* Ограничения
  * Срок — 2 месяца

#### Целевое решение

* Требования:
  * ликвидация локального железа
  * перевод кассового ПО на Cloud POS ("тонкий клиент") 
  * работа в магазине выстроена планшет и фискальный регистратор
  * Снижение затрат на ИТ-поддержку региональной сети на 40%
  * Автоматическая адаптация под любые платёжные системы и терминалы через Payment Gateway
* Ограничения
  * Срок - год

#### Риски

* Срыв сроков открытия магазина из-за уникального оборудования
* Остановка бизнеса из-за поломки локального оборудования
* Потеря продаж из-за простоя программы лояльности при отключении сети интернет
* Денежные потери из-за неверного маппинга данных магазина

### Решение
-  Кассовое ПО: SaaS Мой склад (включая лояльность)
-  Локальный сервер магазина: заменяем на планшет Android
-  Оборудование: если оборудование магазина поддерживается в Мой склад, то не заменяем, в остальных случаях требуется замена оборудования
-  Удаленная настройка в магазинах: Kaspersky Endpoint Security + Агент на планшете
-  Оффлайн-режим: встроенное решение SaaS Мой склад
-  HAL/Payment Gateway: SAAS Мой склад
-  on-premises Системы ЦО: требуется доработка для асинхронного взаимодействия с облачной шиной 
-  Коммуникация процессов: SaaS Битрикс24
-  Автоматизация онбординга: PaaS Yandex (YandexGPT API, Yandex Object Storage, Yandex Managed Service for YDB,  Yandex Cloud Functions)
-  Безопасность внутреннего контура:  PaaS Yandex API Gateway
-  Событийное взаимодействие: PaaS Yandex Data Streams +  Yandex Cloud Functions
-  BI-отчётность: SaaS Yandex DataLens
